## Introduction

Exp is an **SDK**, providing export and import functionalities which helps to communicate 
between different programming languages.

For example , you have a functions written in Python and you want to use it in you Javascript codebase, 
here comes Exp to help you achieve that. It provides methods to export functions from one languages  to another.
